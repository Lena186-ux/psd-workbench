Privacy policy.

Your files

Selected PSD files are read using browser APIs and processed in a Web Worker on your device. The workbench has no endpoint for uploading file contents, file names or exported PNGs. Files are held in browser memory during use. Clear the workbench or close the page to release its references; browser and operating system memory management is outside our control.

Website requests

The site is hosted by Vercel. Loading the website sends ordinary network requests to the hosting provider, which may process IP addresses, request URLs, user-agent information and operational logs. See Vercel's privacy policy. We do not promise that visiting this site creates no logs.

Cookies and analytics

This version adds no advertising, analytics trackers, account system or application cookies. It does not store selected files in browser storage. Downloaded PNGs are saved wherever your browser places downloads.

External links

Linked third-party sites have their own policies. They receive ordinary requests when you visit them.

Updates and questions

This policy will be updated when data handling changes. For a public question, open an issue in the project's source repository listed on the open-source page. Do not attach private PSD files.
