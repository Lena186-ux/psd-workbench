PhotoCraft and PSD Workbench: choose by task

PhotoCraft is a separate open-source image editor. Its official repository describes a Rust implementation with layered PSD editing capabilities. Follow its official project website and documentation for current downloads, platform support and feature details. PSD Workbench is an independent browser utility; it does not run the PhotoCraft editor engine.

Before opening a PSD in another application

Keep a copy of the original document. Identify the colour mode, bit depth, dimensions and any external dependencies in the application that created it. A file can contain text, vector objects, effects, smart objects and linked assets, so successfully reading its preview does not establish full editing compatibility.

Separate the result you need from the format you were sent. If the next person needs only a reference image, a reviewed PNG may be sufficient. If they must change text or adjust layers, send the PSD and the necessary resources through an appropriate channel. A PNG cannot preserve those editing controls.

A viewing workflow for a compatible PSD

Start with the online PSD viewer when your immediate question is what the saved document looks like or how its layers are organized. Select an 8-bit RGB or grayscale PSD within the stated limits. Check the image dimensions, saved composite and layer metadata. Hidden layers may contain alternatives that are not visible in the saved image.

If the preview cannot be decoded, the layer list may still be available. Read the status message and return to the originating editor if you need a reliable full rendering. The viewer cannot recomposite the document or repair missing saved pixels.

A PNG handoff workflow

Use the PSD to PNG converter to export the stored composite, then review the downloaded image before sharing it. The source PSD remains unchanged. Preserve it when an editable source may be needed later.

Individual layer downloads contain cropped raw pixels. They do not apply masks, effects, opacity, blend modes or document positioning. If the required asset must include its final appearance in the design, render and export it from an editor. This distinction prevents a raw bitmap from being mistaken for a finished composited asset.

An editing workflow for PhotoCraft or another editor

Check the chosen editor's current documentation against the features your file uses. Open a copy, inspect important areas and compare the result with a trusted reference image. Review text placement, masks, effects, colour and linked content before committing changes to a working file. Save under a separate name when evaluating compatibility.

This guide does not certify PhotoCraft support for every PSD feature, operating system or release. It points you to the project's own materials so you can assess the current version. A viewable saved composite in PSD Workbench is not evidence that another application can edit every component of that file.

Work around unsupported files in PSD Workbench

The browser utility does not support PSB, CMYK, Lab, indexed colour or 16/32-bit documents. It also has limits for file size, pixel dimensions and the layer tree. Use the original editor to export a PNG directly, or create a separate 8-bit RGB or grayscale PSD with a compatible merged image. Keep the original colour-managed document when that matters to your work.

A reduced copy can make browser inspection more practical on a device with limited memory. Choose that copy only after deciding which information can be omitted; reducing dimensions or changing colour mode may affect the document. The viewer is a convenience for inspection, rather than an archival conversion format.
