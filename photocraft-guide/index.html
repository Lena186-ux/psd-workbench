What is PhotoCraft?

PhotoCraft's official repository describes an open-source image editor built in Rust, with native and WebAssembly support. Its README labels the project early alpha and says it is not yet a replacement for daily professional Photoshop work. Check its current documentation and releases for supported capabilities.

When to use PSD Workbench

Use our PSD viewer for a quick look at a compatible document's saved composite and layer tree. Use PSD to PNG to extract existing pixels for a handoff. This site does not run the PhotoCraft engine and does not provide editing tools.

When to use an editor

Changing text, editing masks, applying adjustments and saving a layered document require an editor. Consult PhotoCraft's official documentation for its current support, or use the application that created the PSD. Keep backups when trying alpha software.

Compatibility before conversion

For this workbench, use an 8-bit RGB or grayscale PSD and save a merged composite in your editor. PSB and other colour modes are unsupported. Exporting layer pixels does not reproduce masks or effects.

Source and identity

PhotoCraft's source code is offered under MIT or Apache-2.0; its asset attribution file lists separate third-party asset licenses. We do not reuse its branding, screenshots or bundled assets. PSD Workbench is an independent project and is not the official PhotoCraft website.
