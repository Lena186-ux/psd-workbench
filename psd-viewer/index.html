KNOW YOUR FILE

A workbench, with clear edges.

What works

8-bit RGB and grayscale PSDs with saved composite pixels. Layer metadata and stored raster layer exports. A modern browser with Web Workers and OffscreenCanvas.

What needs your editor

PSB, CMYK, Lab, indexed colour and 16/32-bit documents are not supported. This tool does not edit PSDs, render text or vector shapes, apply masks or effects, or rebuild the composite from layers. Colour profiles are not managed; exports may differ from a colour-managed editor.

No preview? Open the file in its original editor and re-save with a compatible merged image. Keep the original PSD.

A few things to know.

Are my PSD files uploaded?

The workbench reads the file through the browser's File API and processes it in a local Worker. It has no file upload API. Hosting services still receive ordinary page requests and may log IP addresses and request details. See our privacy policy.

Does exporting change my original PSD?

No. The tool reads the selected file and creates a new PNG download. It does not write back to your PSD.

Why doesn't a layer export match the full design?

A layer export is its stored raster bitmap, cropped to the layer dimensions. Masks, effects, opacity, blend modes and document positioning are not applied. Use the saved composite for the full document appearance.

Can I use it on my phone?

The layout works on small screens. Processing is limited by device memory; smaller documents work best. Large documents may require a desktop browser.
