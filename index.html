How to use the online PSD viewer

  1. Choose your PSD. Drop one file into the viewer or use the file button. Start with an 8-bit RGB or grayscale document under 80 MB. You do not need an account or an installed editor to inspect a compatible file.
  2. Read the saved preview. The viewer displays the composite image already stored inside the PSD. This is a saved snapshot of the document, rather than a fresh rendering of every layer. Check the document dimensions above the preview.
  3. Inspect the layer tree. Browse the list for layer names, group nesting, stored dimensions, visibility, opacity and blend mode. These details help you understand how the document is organized before reopening it in an editor.
  4. Continue your handoff. Keep the original file for editing. If you need a flat image, use the export button or follow the dedicated PSD to PNG conversion guide. Select Clear when you are finished inspecting the document.

What you can learn from a PSD preview

A PSD viewer is useful when a collaborator sends you a design and you need to understand the file before deciding what to do next. The saved composite gives you a quick view of the overall layout. The layer tree provides a second view of the document: names, groups and dimensions can explain how the artwork was assembled even when the preview is unavailable.

For a design handoff, compare the document width and height with the requested output size. Look for clearly named groups and layers that belong to the relevant screen or asset. Hidden layers can represent alternative artwork, so the presence of a layer in the list does not mean it appears in the saved image. The opacity and blend mode values are metadata, rather than interactive controls.

For an archive, a local preview can help identify a compatible file without opening a full editing session. For a developer receiving an asset, the dimensions and available raster layers can clarify whether the file contains a usable image. A successful preview alone does not establish that every font, linked resource or editable object is present. Confirm those requirements in the originating editor.

PSD viewer compatibility and document limits

This online PSD viewer accepts 8-bit RGB and grayscale PSD documents. A modern browser must support Web Workers and OffscreenCanvas. The workbench limits input to 80 MB, document and bitmap dimensions to 10,000 pixels per side and 25 million pixels, and the layer tree to 300 layers or groups with up to 30 nested levels. These safeguards bound processing; a file inside the limits can still fail if its data is unsupported or damaged.

PSB documents, CMYK, Lab, indexed colour and 16-bit or 32-bit channels are outside this viewer's supported range. Renaming a PSB file to PSD does not convert it. Use an editor to create a separate compatible copy, preserving the original document and its colour information.

The viewer uses saved pixels. It does not edit text, resolve fonts, draw vector shapes, apply masks or effects, render smart objects, or rebuild a composite from layers. A PSD containing such features may still provide a saved composite that can be displayed. That preview is not a promise that its editable features can be reconstructed here.

Colour profiles are not managed. The displayed preview and exported PNG may differ from a colour-managed editor, particularly when a document relies on a specific profile. Use your original editor for colour-critical review and production output. The browser workbench is intended for inspection and extraction of existing pixels.

Troubleshooting a PSD that will not open

No saved composite image

Some documents contain layer information without a usable saved composite. The viewer may show a warning while still listing the layers. Open the original document in its editor and save a separate 8-bit RGB or grayscale PSD with a compatible merged image. Then choose that copy in the viewer. Saving a merged image does not mean flattening your only original.

Unsupported format or a large document

Read the error message before trying again. If the file exceeds the size, pixel or layer limits, prepare a smaller copy in your editor. If its colour mode or bit depth is unsupported, export a compatible copy there. Processing can also stop when a device runs out of memory; a desktop browser may be more suitable for a complex document.

A preview that looks different

Compare the saved composite with a fresh export from the originating editor. Changes to layers, missing saved pixels and colour management can affect the result. This PSD viewer cannot repair or recomposite a document. For an exact rendering, use the editor and resources that produced the design.

Online PSD viewer questions

Can I view a PSD without Photoshop?

For supported documents, yes: select the PSD in this viewer to inspect its saved image and layer metadata. Editing text, changing layers and saving a layered document require an editor.

Are my PSD files uploaded to a server?

File contents are read through the browser File API and processed in a local Worker. There is no file upload endpoint or account. Hosting services receive ordinary page requests and may record request details. Read the privacy policy for that distinction.

Can I hide layers or change the preview?

The layer list is for inspection. It does not toggle visibility or update the composite. Visibility, opacity and blend mode describe the stored document; they are not editing controls.

Can the viewer extract individual layers?

A PNG button is available for stored raster layers with pixel dimensions. It exports the cropped raw bitmap. Masks, effects, opacity, blending and document positioning are not applied. See the layer export explanation before using the result.

Does viewing or exporting overwrite the PSD?

No. The workbench reads the selected file and creates separate PNG downloads. It does not write back to the PSD. Keep the original as your editable source.

Will the online PSD viewer work on a phone?

The interface adapts to smaller screens, but parsing depends on browser support and available device memory. Try a small compatible file first. Large documents may require a desktop browser.

Where should I go if I need an editor?

Use an editor that supports your document and required features. Our independent PhotoCraft and PSD workflow guide explains how to separate viewing, conversion and editing needs, with links to upstream documentation.
